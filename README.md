HR Analytics Dashboard (Power BI)

This Power BI project visualizes HR data to analyze employee attrition and key workforce trends.  
It was created *for learning purposes* by following a YouTube tutorial and rebuilt independently to understand Power BI dashboard design and data visualization concepts.

Project Overview:

The *HR Analytics Dashboard* provides insights into:
- Overall employee count, attrition rate, and active employees  
- Department-wise and education field-wise attrition  
- Attrition rate by age group and gender  
- Job satisfaction by job role  
- Average employee age and other key HR metrics  

This helps HR teams identify retention patterns and workforce trends across departments and demographics.

Through this project, I learned:
